##  Про проєкт

«Видатні постаті» — це інформаційний вебсайт, присвячений життю, творчості та культурній спадщині видатного українського поета, художника та громадського діяча Тараса Григоровича Шевченка.

Мета проєкту — познайомити користувачів із біографією Кобзаря, основними подіями його життя та мистецькими досягненнями.

##  Про Тараса Шевченка

**Тарас Григорович Шевченко (1814–1861)** — видатний український поет, прозаїк, драматург, художник і громадський діяч. Його творчість стала важливою частиною української культури та літератури.
